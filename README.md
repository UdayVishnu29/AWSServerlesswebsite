This project is a fully serverless web application deployed on AWS. It provides a secure user authentication system, a static website hosted on Amazon S3, REST APIs using Amazon API Gateway and AWS Lambda, user data storage with DynamoDB, and image storage in Amazon S3. The frontend is automatically built and deployed using AWS Amplify, which integrates directly with GitHub for Continuous Integration and Continuous Deployment (CI/CD).
